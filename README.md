FamLite Split is a minimalist, easy-to-use mobile application designed to simplify task splitting and management for small groups. 
Unlike professional task management tools with steep learning curves, 
Split offers a streamlined interface that allows a group leader to quickly create tasks and assign them to members—either manually or 
automatically—without unnecessary complexity
